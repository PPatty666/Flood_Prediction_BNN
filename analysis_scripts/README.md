# 📦 Project environment & code usage

Hi there! 👋  

This repository contains the full codebase used to **train, investigate, and evaluate the model and its predictions**. The code is structured so that you can:

- 🔹 Train the model from scratch   
- 🔹 Analyze and investigate model predictions  
- 🔹 Reuse and adapt the workflow to update or retrain the model with new data  

Everything included here reflects the setup used by the author during development and testing.

---

# 🧪 Reproducible environment

The provided `environment.yml` file allows you to recreate the exact Conda environment where the code was:

- Implemented  
- Tested  
- Verified  

This is to make sure the code runs consistently and reproducibly across different systems.
---

# 🚀 How to set up the environment

### 1️⃣ Create the conda environment

conda env create -f environment.yml

### 2️⃣ Activate the environment

conda activate <environment_name>
